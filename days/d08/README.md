# День 8. RAG своими руками

Блок: RAG

## Зачем

RAG — самый востребованный шаблон в корпоративном ИИ. Собрав его без фреймворка, ты будешь понимать, что именно делает любая библиотека и где она ломается.

## Задание (ката)

Открой `d08.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d08 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта

Подключи `Retriever` к своим документам и настоящим эмбеддингам. Эндпоинт `/ask` теперь отвечает по документам и возвращает источники.
