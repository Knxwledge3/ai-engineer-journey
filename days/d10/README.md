# День 10. Проект 1: RAG-сервис в интернете

Блок: RAG

## Зачем

Задеплоенный сервис с публичной ссылкой отличает человека, который 'проходил курс', от человека, который 'сделал продукт'.

## Слой продукта

Собери всё в один сервис и выложи. С этого дня тебе можно писать код вместе с ИИ-агентом для кода, при условии правила из TUTOR.md: объясняешь каждую строку.

## Готово, когда

1) Dockerfile собирается локально. 2) Сервис доступен по публичной ссылке. 3) `/ask` отвечает по твоим документам с источниками и говорит 'не знаю' на чужой вопрос. 4) В README есть схема и инструкция запуска. 5) Ссылку получили 3 человека из целевой аудитории, их реакция записана.
