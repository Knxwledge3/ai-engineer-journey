# День 13. Агент своими руками

Блок: Агенты

## Зачем

Агент — это цикл while вокруг модели и словарь функций. Поняв это на 60 строках, ты сможешь отлаживать любой фреймворк.

## Задание (ката)

Открой `d13.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d13 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта

Подключи `run_agent` к настоящей модели: напиши адаптер, который переводит tool use твоего провайдера в формат курса. Первый инструмент — поиск по твоим документам из 8-го дня.

## Готово, когда

Агент на настоящей модели сам решает, искать в документах или отвечать сразу.

## Теория (не больше часа, после первой попытки, а не до)

Статья Anthropic 'Building effective agents' и раздел tool use в документации провайдера.
