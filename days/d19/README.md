# День 19. Деньги, git на рабочем уровне, CI

Блок: Деньги и продукт

## Зачем

Юнит-экономика ИИ-продукта — это токены. Не посчитав стоимость запроса, нельзя назначить цену. А тесты, которые запускаются сами при каждом пуше, — признак профессионального репозитория.

## Задание (ката)

Открой `d19.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d19 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта

Логируй стоимость каждого запроса и поставь дневной лимит. Включи кэширование промптов, если провайдер его поддерживает. Скопируй `templates/tests.yml` в `.github/workflows/`.

## Готово, когда

1) Зелёная галочка CI на GitHub. 2) Одна фича сделана через ветку и pull request. 3) Знаешь стоимость среднего запроса своего продукта в тенге.
