# День 12. Автоматизация: вебхуки и n8n

Блок: Бот и автоматизация

## Зачем

Клиенты покупают не агента, а закрытый процесс: пришла заявка -> разобрана -> ответ ушёл -> запись в таблице. Вебхук соединяет твой код с тысячами готовых сервисов.

## Задание (ката)

Открой `d12.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d12 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта

Собери в n8n сценарий из 4+ шагов с условием, где один шаг вызывает твой `/hook`. Это первая вещь, которую можно показать компании: «заявка пришла, разобрана, ответ ушёл».

## Готово, когда

Сценарий n8n срабатывает от настоящего события (форма, письмо, расписание) и вызывает твой сервис.

## Теория (не больше часа, после первой попытки, а не до)

Документация n8n: Quickstart, Webhook node, HTTP Request node.
