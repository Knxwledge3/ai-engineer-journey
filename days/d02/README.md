# День 2. Первый вызов модели и секреты

Блок: Фундамент

## Зачем

Ключ в публичном репозитории — самая частая и самая дорогая ошибка новичка. А функция, которая получает модель параметром, тестируется без денег и переживает смену провайдера.

## Задание (ката)

Открой `d02.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d02 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта

Напиши `product/llm.py`: настоящая функция `real_llm(messages) -> str`, которая зовёт API. Ключ и имя модели только из `.env` (скопируй `.env.example`). Проверь командой `git status`, что `.env` не попадает в коммит.

## Готово, когда

Скрипт `python product/llm.py` печатает ответ настоящей модели; ключа нет ни в одном файле репозитория.

## Теория (не больше часа, после первой попытки, а не до)

Официальный quickstart твоего провайдера (сейчас у тебя Claude API). Имя модели бери из документации в день занятия, не из старых статей.
