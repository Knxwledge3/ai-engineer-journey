# День 17. Надёжность и безопасность

Блок: Агенты

## Зачем

Агент читает чужие тексты и умеет действовать. Значит, чужой текст может попытаться им управлять (prompt injection). Плюс зависания, утечки ключей в логи и опасные действия без подтверждения.

## Задание (ката)

Открой `d17.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d17 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта

Включи в продукт трассировку каждого шага, таймауты на инструменты, подтверждение опасных действий и обёртку для чужого текста.

## Готово, когда

Ты сам атаковал своего агента документом с вредной инструкцией и записал результат.

## Теория (не больше часа, после первой попытки, а не до)

OWASP Top 10 for LLM Applications: раздел про prompt injection. Раздел о защите от инъекций в документации провайдера.
