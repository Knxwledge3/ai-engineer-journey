# День 6. Эмбеддинги и нарезка текста

Блок: Фундамент

## Зачем

Поиск по смыслу — основа RAG и долгой памяти агентов. Написав косинус и нарезку руками один раз, ты перестанешь воспринимать векторные базы как магию.

## Задание (ката)

Открой `d06.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d06 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта

Нарежь свои документы `chunk_text` и посчитай настоящие эмбеддинги через API или локальную модель. Сохрани в файл, чтобы не платить дважды.

## Готово, когда

По трём своим вопросам `top_k` возвращает осмысленные куски из твоих документов.
