# День 18. Evals для агента

Блок: Агенты

## Зачем

Без набора сценариев любое улучшение промпта — лотерея: починил одно, сломал другое и не заметил. С набором ты меняешь агента смело.

## Задание (ката)

Открой `d18.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d18 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта

Напиши 15-20 сценариев для своего агента: обычные, двусмысленные, провокационные, на зацикливание. Прогон одной командой.

## Готово, когда

Отчёт прогона лежит в `product/evals/`, доля пройденных сценариев записана в log.md.

## Теория (не больше часа, после первой попытки, а не до)
