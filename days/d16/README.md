# День 16. Фреймворк и работа с ИИ-агентом для кода

Блок: Агенты

## Зачем

Фреймворки меняются каждые полгода, поэтому важен не выбор, а умение быстро оценить и освоить любой. Второй навык дня: ставить задачи агенту для кода и проверять его работу.

## Слой продукта

Перепиши своего агента на актуальном агентном SDK, выбранном в этот день (см. RADAR.md). Сравни с самописным: строки кода, прозрачность, что стало проще и что спряталось.

## Готово, когда

1) Агент работает на фреймворке и отвечает на те же запросы. 2) Одна фича сделана через ИИ-агента для кода: ты написал задание, прочитал дифф, нашёл в нём минимум одну проблему. 3) Таблица сравнения в `product/NOTES.md`.

## Теория (не больше часа, после первой попытки, а не до)

Документация выбранного SDK. Выбор делаем в день занятия по RADAR.md, а не по этому файлу.
