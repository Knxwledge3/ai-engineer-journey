# День 15. MCP: стандартный разъём для инструментов

Блок: Агенты

## Зачем

MCP — общий протокол подключения инструментов к моделям. Один раз обернув свои инструменты в MCP-сервер, ты подключаешь их к разным клиентам без переписывания.

## Слой продукта

Оберни инструменты своего продукта в MCP-сервер и подключи к настольному клиенту.

## Готово, когда

1) MCP-сервер с 2+ твоими инструментами запускается. 2) Клиент видит инструменты и вызывает их. 3) В `product/NOTES.md` своими словами: чем MCP-инструмент отличается от функции из 13-го дня и когда MCP не нужен.
