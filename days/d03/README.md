# День 3. Промпты как код и первый eval

Блок: Фундамент

## Зачем

Промпт без набора проверок — это мнение. С набором проверок — инженерия: ты меняешь формулировку и видишь, стало лучше или хуже. Это главный навык курса.

## Задание (ката)

Открой `d03.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d03 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта

Собери `product/evals/cases.json`: 10 вопросов по своим документам с ожидаемыми ответами. Этот файл ты будешь пополнять до конца курса.

## Готово, когда

Два варианта одного промпта сравнены на своих 10 примерах через `run_eval`, цифры записаны в `product/evals/log.md`.

## Теория (не больше часа, после первой попытки, а не до)

Руководство по промптам в документации Anthropic: разделы про чёткие инструкции, примеры и XML-теги.
