# День 5. Внешние API и ошибки

Блок: Фундамент

## Зачем

В проде сеть падает каждый день. Сервис, который не отличает временную ошибку от постоянной, либо сдаётся слишком рано, либо долбит сервер впустую.

## Задание (ката)

Открой `d05.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d05 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта

Подключи один внешний источник данных, нужный продукту (курс валют, погода, цены), через `fetch_json` + `with_retries`.

## Теория (не больше часа, после первой попытки, а не до)

Коды HTTP (2xx, 4xx, 5xx, 429) и понятие exponential backoff. 20 минут.
