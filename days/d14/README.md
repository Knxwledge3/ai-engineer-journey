# День 14. Инструменты и память диалога

Блок: Агенты

## Зачем

Качество агента определяется качеством инструментов и их описаний. А eval('...') от модели — это дыра размером с весь сервер.

## Задание (ката)

Открой `d14.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d14 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта

Добавь 3-4 инструмента, нужных именно твоему продукту, через `tool_spec`. Подключи `Conversation`.
