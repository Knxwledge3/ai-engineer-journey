# День 11. Telegram-бот и расписание

Блок: Бот и автоматизация

## Зачем

В Казахстане и СНГ Telegram — самый короткий путь к пользователю: не нужен ни сайт, ни приложение.

## Задание (ката)

Открой `d11.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d11 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта

Бот-интерфейс к твоему RAG-сервису из 10-го дня с командами /start, /help, /ask, /reset. Ежедневный дайджест по расписанию. Сообщение тебе в личку, если что-то упало.

## Готово, когда

Бот отвечает с телефона; дайджест пришёл сам по расписанию; при искусственной поломке пришло уведомление.

## Теория (не больше часа, после первой попытки, а не до)

Telegram Bot API: getUpdates, sendMessage, webhooks. Библиотеку выбери актуальную в день занятия.
