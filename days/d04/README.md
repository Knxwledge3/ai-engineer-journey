## Зачем

Программа не может работать с 'примерно таким' текстом. Нужны поля с типами и план на случай, когда модель ошиблась форматом.

## Задание (ката)

Открой `d04.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d04 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.

## Слой продукта
