## Задание (ката)

Открой `d01.py`. В каждой функции описано, что она должна делать. Замени `raise NotImplementedError` своим кодом.

Проверка:

```
python -m pytest days/d01 -q
```

Все тесты зелёные = ката сдана. Тесты читать можно и нужно: это точная спецификация.
